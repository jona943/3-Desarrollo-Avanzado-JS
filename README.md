Repositorio central del **Módulo 3: Desarrollo Avanzado en JavaScript (Asincronía, Consumo de APIs REST, Módulos ES6 y Vite)** perteneciente al **Master en Frontend Asistido con IA**. Este módulo explora la programación asíncrona profunda, el Event Loop, peticiones HTTP, validación de formularios avanzadas, modularización y empaquetado de aplicaciones con Vite.

## <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/linux/linux-original.svg" width="22" height="22" valign="middle" /> Competencias y Contenidos Clave

* **Asincronía & Event Loop**: Pila de ejecuciones (Call Stack), cola de microtareas y temporizadores asíncronos (`setTimeout`, `setInterval`).
* **Promesas & Async/Await**: Manejo limpio de flujos asíncronos sin caer en Callback Hell y captura de excepciones con `try/catch`.
* **Consumo de APIs REST**: Peticiones HTTP (`GET`, `POST`) mediante Fetch API y renderizado dinámico de JSON en el DOM.
* **Módulos ES6 (`import`/`export`)**: Organización de código modular y separación de responsabilidades.
* **Empaquetamiento con Vite**: Configuración de entorno de desarrollo rápido e integración de proyectos empaquetados modernos.
